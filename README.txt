BTC KALSHI PRO ULTIMATE

Incluye:
- Velas de Binance BTC/USDT en 1m, 5m y 15m.
- EMA 9/21, RSI 14, MACD, VWAP, Bandas de Bollinger, ATR y volumen.
- Confirmación de tendencia entre 1m, 5m y 15m.
- Señales técnicas SUBE / BAJA / ESPERAR.
- Niveles ilustrativos de entrada, stop y objetivos por ATR.
- Calculadora de riesgo y tamaño estimado de posición.

INSTALACIÓN:
Sube TODOS los archivos de este ZIP a la raíz de tu repositorio GitHub (reemplaza los anteriores).
Activa GitHub Pages desde Settings > Pages > Deploy from a branch > main > /(root).
Abre la URL HTTPS en Safari y usa Compartir > Añadir a pantalla de inicio.

IMPORTANTE:
Necesita internet. Usa datos públicos de Binance BTC/USDT. La gráfica depende de Lightweight Charts desde CDN.
Las señales son informativas, no garantizan resultados, no son asesoría financiera y no ejecutan operaciones.
El tamaño calculado no incluye comisiones, deslizamiento, apalancamiento ni riesgo de liquidación.
